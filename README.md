# CodeLab 3D

Обучающая 3D-игра-головоломка, в которой нужно программировать робота: составлять программы из команд, циклов и условий и проводить его к цели. Курсовой проект по дисциплине «Разработка интерактивных мультимедийных приложений».

Движок: **Godot 4.7** (GDScript). Платформы: Windows, macOS.

## Возможности

- 7 уровней: последовательность команд, повороты, циклы, условия, ключи и двери, кнопки и силовые поля, финальное испытание.
- Редактор программы с вложенными блоками «Повторить N раз» и «Если впереди…», перетаскивание команд мышью, пошаговое выполнение, настраиваемая скорость, подсказки и эталонные решения.
- Интерактивные объекты: ключ, запертая дверь, кнопка, силовое поле.
- Главное меню, выбор уровня, пауза, настройки громкости и скорости, сохранение прогресса.
- Звук и музыка, 3D-графика с собственным освещением.

## Управление

| Действие | Как |
|---|---|
| Добавить команду | нажать кнопку команды или перетащить её в программу |
| Выбрать блок для вложенных команд | нажать на заголовок блока |
| Вращать камеру | правая кнопка мыши |
| Масштаб | колесо мыши |
| Пауза и меню | `Esc` |

## Запуск из исходников

1. Установите [Godot 4.7](https://godotengine.org/download) (подойдёт обычная и .NET-версия; C# в проекте не используется).
2. Откройте проект (`project.godot`) и нажмите `F5`.

## Готовые сборки

Собранные версии для Windows и macOS выкладываются в разделе **Releases**.
На macOS приложение не подписано: откройте его через правую кнопку → «Открыть».

## Автоматическая проверка

Игра умеет сама проходить все уровни эталонными решениями:

```bash
godot --headless --path . res://scenes/main.tscn -- --selftest
```

Код возврата `0` — все уровни пройдены.

## Структура проекта

| Путь | Назначение |
|---|---|
| `scripts/levels.gd` | данные уровней и эталонные решения |
| `scripts/board.gd` | игровое поле, объекты (ключи, двери, кнопки, поля) |
| `scripts/robot.gd` | робот и его анимации |
| `scripts/interpreter.gd` | интерпретатор программы пользователя |
| `scripts/main.gd` | игровая сцена и редактор программы |
| `scripts/menu.gd` | главное меню |
| `scripts/game.gd` | прогресс, настройки, переходы между сценами (автозагрузка) |
| `scripts/sfx.gd` | звуки и музыка (автозагрузка) |
| `scripts/palette.gd`, `ui/theme.tres` | цветовая палитра и тема интерфейса |
